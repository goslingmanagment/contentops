# ContentOps

ContentOps — система учёта и оборота всего контента агентства: единый каталог,
происхождение, задачи, размещения, vault-инвентарь и сверка публикаций. Сама на площадки
не ходит: публикует человек руками или Hub по строке плана.

**Статус (14.11.2026):** продукт работает в ВМ `contentops` на winpc с настоящей базой,
адрес — `https://contentops.gosling-agency.ru`, вход через хаб. Идёт обкатка на Ари
(PLAN, «Обкатка на Ари»): её архив и всё новое в каталоге, план и сверка ведутся; Лора
загружена частично и ждёт своей очереди. Не включено: разметка ИИ (нет ключей и бюджета)
и живая отправка постов через Hub (ждёт первой утверждённой недели).

## Как это работает

Путь файла — слева направо, каждый шаг виден на своём экране.

1. **Источник.** Модель сдаёт контент в Telegram, ночное зеркало кладёт его в её Dropbox
   по папкам: `1. PPV`, `2. FYP`, `3. Customs`, `4. Sets`, `5. Sextings`, `6. Life`,
   `8. Other`, внутри — папки дней `ДД.ММ.ГГ`. ContentOps диск только читает.
2. **Забор с диска.** Раз в несколько минут ContentOps смотрит, что нового, скачивает
   файлы к себе, сжимает видео, делает превью и кадры. Очереди и место на дисках —
   «Настройки › Состояние».
3. **«Приехало».** Каждая новая папка — группа. Готовую группу принимают одной кнопкой;
   у спорной сначала вопрос ◆: что это за тип, копия это или новый ролик, разделить ли
   несколько роликов, к какому заказу кастом. Не контент (скриншоты, рабочая переписка)
   отклоняют с причиной.
4. **Библиотека.** Принятая группа становится объектом с номером, который больше не
   меняется: `PPV-018`, `SET-045`, `FYP-0039`, `CUS-036`, `SXT-004`, `LIFE-044`, `RAW-0094`.
   В карточке — файлы, просмотр, название и описание, где объект уже выходил, скачивание
   и «В план». Сырьё для монтажа — `RAW`, готовые фупы монтажёра — `FYP`.
5. **Кастомы.** Заказ живёт в Hub (карточка из Telegram, покупатель, срок). Рутина
   `customs-daily` раз в день читает Telegram и ведёт заказы; ролик из `3. Customs`
   при приёмке становится сдачей своего заказа, и заказ переходит в «сдан».
6. **План.** У страницы есть норма недели (у ari-1: фуп каждый день в 14:00, стена во
   вт, ср и сб в 20:00). Строка плана — объект, страница, место (стена, фуп, vault), день
   и время, подпись. К строке заранее готовится файл для площадки с именем, по которому
   пост потом узнаётся.
7. **Публикация.** Два способа. Руками: скачать файл из строки, выложить, поставить
   отметку. Через Hub: «Подготовить» создаёт черновик в Hub, «Отправить» ставит его в
   расписание площадки. Агент отправляет только бесплатные посты недели, которую владелец
   утвердил кнопкой «Утвердить неделю»; платные посты и цены — только человек.
8. **«Сверить».** Раз в час Hub отдаёт, что реально вышло на странице. Пост, выложенный
   нашим файлом, сам привязывается к строке плана. Остальное — вопросы: пост похож на
   строку, но не точно; пост вышел без плана («Привязать» к объекту или «вне каталога»);
   строка не вышла вовремя — «пропущено».
9. **Журнал.** Кто что сделал: человек, агент или сама система, с результатом.

## Кто что делает

- **Владелец** — утверждает неделю, решает про цены, платные посты и удаление, включает
  и выключает интеграции («Настройки › Интеграции»).
- **КМ** — приёмка, названия, план, сверка. У Ари КМ нет: его решения принимает агент
  «Оператор», в журнале это видно как «подтверждено агентом».
- **Агенты** (все ходят через тот же API, что и люди, с правами и журналом): «Оператор» —
  приёмка, план и сверка Ари; «Агент заказов» — рутина `customs-daily`; «Генгар» — заливка
  в vault через Hub. Выключаются все разом выключателем «Агенты».
- **Hub** — люди и вход, заказы кастомов, зеркало постов страницы, отправка публикаций.

## Где что смотреть

| Что | Где |
| --- | --- |
| Новое с диска | «Приехало» |
| Всё принятое, поиск по номеру и словам | «Библиотека», строка поиска |
| Заказы кастомов | «Библиотека › Кастомы › Заказы» |
| Что выходит на этой неделе | «План › Неделя» |
| Что вышло не по плану | «План › Сверить» |
| Очереди, диски, копия базы | «Настройки › Состояние» |
| Подключения к Dropbox и Hub, выключатели | «Настройки › Интеграции» |
| Норма недели страницы | «План › Нормы» |
