# ContentOps

ContentOps — система учёта и оборота всего контента агентства: единый каталог,
происхождение, задачи, размещения, vault-инвентарь и сверка публикаций. Сама на площадки
не ходит: публикует человек руками или Hub по строке плана.

**Статус:** документация приведена к структуре PRD → SPEC → PLAN. Подэтап 1б закрыт:
образец интерфейса принят владельцем 28.09.2026. Код продукта ещё не начат; он будет
жить в этом репо, в корне (`apps/`, `packages/`; решение 30.09.2026). Сейчас есть
конвейер сжатия в `tools/` и прототип интерфейса на моковых данных в `design/`.
